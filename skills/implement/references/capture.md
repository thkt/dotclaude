# Capture settings and the media an Issue requires

The `capture` entry in `.dotagents.json` decides when `launch.ts` captures and when it replaces the media in `destination`. Write the Issue's required media and where they go to match that behavior. When the setting and the Issue's requirements disagree, the review returns a required finding, and repair and review make no progress and stop. This repo bundles the Playwright adapter that `{harness}` in the capture command points to. `launch.ts` runs the capture outside the sandbox. On macOS, Chromium cannot start inside the Claude Code sandbox (Mach service registration is denied, and no setting allows it). When `launch.ts` is called inside the sandbox, the capture stops with `capture-unavailable`. A target's `capture.command` calls `bun {harness}/scripts/capture/capture.ts SPEC CONFIG`.

`required: false` does not mean the media stay unchanged. An Issue that changes a screen and says "do not update the media" contradicts the capture of `launch.ts`, and the review stops. When a change should keep the media, ask the human whether to change the `capture` setting.

The capture replaces the content of `destination` with the captured media. Put only media in `destination`. The captured media go into the accepted tree and appear in the `## Media` section of the PR body.

| Setting           | What `launch.ts` does                                                                                                                                                                                      | What the Issue states                                                                                                       |
| ----------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| `capture: null`   | Never captures                                                                                                                                                                                             | The agreement that no media are needed                                                                                      |
| `required: true`  | Always captures on the first round, whatever changed, and replaces the media in `destination`                                                                                                              | The screens and operations to capture, and that the media in `destination` get replaced                                     |
| `required: false` | Skips the capture when only plain Markdown changed, and keeps the existing media. Any other change, such as code, config, a capture definition, or media, captures and replaces the media in `destination` | For an Issue that changes a screen, the screens and operations to capture, and that the media in `destination` get replaced |
